## 二、怎么进入系统

### 电脑（这台机器）

```
http://localhost:3200/login
```

### 手机 / 平板（连同一个 WiFi）

```
http://192.168.1.30:3200/login
```

### 部署到腾讯云之后

```
http://<服务器IP>:3200/login
```

部署完成后把这里的 IP 换成服务器地址即可，账号密码不变。

**三个小提示**

1. 手机浏览器打开后，选「添加到主屏幕」，以后就是图标点开，跟 App 一样。
2. 不要在微信里直接点链接打开，页面会被压缩，请用系统浏览器（Safari / Chrome）。
3. 不要用「无痕 / 隐私模式」，否则每次都要重新登录。

## 三、学生端怎么用：每天只走这六步

打开「今日训练」，从上往下依次是：

| 步骤 | 名称 | 做什么 | 时长 |
|---|---|---|---|
| 1 | **成功热身** | 从已经会的题开始，先把状态找回来 | 2–3 分钟 |
| 2 | **知识复测** | 按 1/3/7/14/30 天的节奏回顾旧知识；还没学过的先给一道预热题 | 3–5 分钟 |
| 3 | **微知识学习** | 今天只学一个小点：生活情境 → 核心概念 → 公式 → 常见坑 → 例题 | 5 分钟 |
| 4 | **专项训练** | 同一个知识点连做 5 题：原型题 → 换问法 → 换情境 | 10 分钟 |
| 5 | **独立通关** | 不给任何提示做 2 题，检验「离开提示还会不会」 | 5 分钟 |
| 6 | **今日总结** | 看今天真正修好了什么，并选一个难度感受 | 1 分钟 |

合计约 **25–28 分钟**。

### 卡住了怎么办

每题下面有「要一个提示」按钮，分三层递进：

1. **提示 1 · 方向** —— 只告诉你往哪儿想
2. **提示 2 · 关键条件** —— 点出题目里哪个条件有用
3. **提示 3 · 公式框架** —— 给出公式骨架

用了几层提示会被记录下来，用来判断「是真会，还是靠提示做对的」。**独立通关那 2 题不给提示**，这是故意的。

### 做错之后

1. 先看解析（不是只给答案，是讲为什么）；
2. 选「错因自诊」——概念没懂 / 公式记错 / 审题漏条件 / 计算失误 / 单位没换；
3. 系统会按你选的错因，把这类题安排到之后几天的复测里。

> 错因一定要认真选。选对了，系统才知道该给你补什么；随便点一个，它就补错方向。

## 五、物理和化学怎么切换

系统默认**一天一科**为主线（今天物理，明天化学）。

如果某天被事情耽误了，另一科**可以直接切过去补**：今日训练页顶部有「物理 / 化学」两个标签，两科各自记录自己的进度，互不覆盖、互不清零。

> 这样设计是考虑到孩子的时间经常被别的事打断，不必因为漏了一天就整周乱掉。

## 七、给孩子的三条建议

1. **每天 25 分钟，好过周末补两小时。** 这套系统的复测节奏是按遗忘曲线排的，断掉就白排。
2. **不会就用提示，别硬扛。** 用提示做对也算进步，但只有独立做对才算「掌握」——所以独立通关别偷偷看解析。
3. **错因认真选。** 这是系统唯一能听懂你「哪里没懂」的方式。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 提示「账号或密码错误」 | 检查账号前后有没有多打空格；连续输错多次会被临时限制，等 1 分钟再试 |
| 页面空白 / 一直转圈 | 刷新一次；手机上确认连的是同一个 WiFi |
| 进去没看到今天的计划 | 刷新会自动生成，第一次进入需要几秒 |
| 换手机 / 换电脑成绩还在吗 | 在。所有进度存在服务器，换设备登录接着做 |
| 做到一半关了页面 | 已做的题都保存了，重新打开从没做完的那一步继续 |
| 想给孩子重置进度 | 找管理员处理，重置后从头开始，慎用 |
