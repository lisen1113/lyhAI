三、学生端：每天只走这六步

打开「今日训练」，从上往下依次是 —— 全程约 25–28 分钟。

成功热身 2–3 分钟
从已经会的题开始，先把状态找回来。开局不打击信心。
知识复测 3–5 分钟
按 1 / 3 / 7 / 14 / 30 天的节奏回顾旧知识；还没学过的，先给一道同单元的预热题。
微知识学习 5 分钟
今天只学一个小点：生活情境 → 核心概念 → 公式 → 常见坑 → 例题。看完点「我学会了，去练习」。
专项训练 10 分钟
同一个知识点连做 5 题：原型题 → 换问法 → 换情境。学的和练的必须是同一个点。
独立通关 5 分钟
不给任何提示做 2 题，检验「离开提示还会不会」。做不出来也没关系，看完解析再来。
今日总结 1 分钟
看今天真正修好了什么，并选一个难度感受：容易 / 正合适 / 有点难。

卡住了怎么办：三层递进提示

提示 1 · 方向只告诉你往哪儿想，不给答案。
提示 2 · 关键条件点出题目里哪个条件有用、哪个是干扰。
提示 3 · 公式框架给出公式骨架，最后一步还是要自己算。
用了几层提示会被记录，用来判断「是真会，还是靠提示做对的」。独立通关那 2 题不提供提示——这是故意的，因为只有独立做对才算掌握。

做错之后的两件事

  1. 先看解析，不是只给答案，是讲为什么；
  2. 选错因自诊：概念没懂 / 公式记错 / 审题漏条件 / 计算失误 / 单位没换。

系统会按你选的错因，把这类题安排进之后几天的复测里。错因一定要认真选——这是系统唯一能听懂你「哪里没懂」的方式；随便点一个，它就补错方向。

五、物理和化学怎么切换

系统默认一天一科为主线（今天物理，明天化学）。

如果某天被事情耽误了，另一科可以直接切过去补：今日训练页顶部有「物理 / 化学」两个标签，两科各自记录自己的进度，互不覆盖、互不清零。

这样设计是考虑到孩子的时间经常被别的事打断，不必因为漏了一天就整周乱掉。
